Entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun.

`main.ts` writes one museum label to `/output/entry.txt` — the label a museum
in the year 3000 puts beside a lift's close-door button, the famously placebo
button passengers hammer in a metal box.

The program is offline and deterministic: no network, no randomness, no API
calls. Run it with Node 22+:

```sh
node main.ts
```
